This afternoon the 3 MB CI log went into the coding agent's context and had to be summarized. ToolOutputLimits keeps it out to begin with. 📄

The problem: one tool call can return far more than the model should read.

The fix: when a tool returns more than the limit, the output is stored instead of sent. Here it went to a file in the workspace, and the model got a short note with the size, a preview and the path.

The result: the agent, on Claude Sonnet 5.5, grepped the file, found "AssertionError: 11400 != 5400", and fixed the bug. Its largest request was 5,901 tokens. With compaction alone, two requests went past 40,000 and the run cost $0.120. This one cost $0.026.
