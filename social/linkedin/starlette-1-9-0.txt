Starlette 1.9.0 is out! 🚀

The highlight is streaming in TestClient. client.stream() now returns as soon as the response starts, instead of waiting for the application to finish. You can test streaming endpoints chunk by chunk. Closing an unfinished streamed response now cancels the application, so check your tests if they relied on the app running to completion.

Also in this release:

- request.url percent-encodes ?, # and a leading // in the path, so they no longer change how the URL is parsed.
- Host routing and TrustedHostMiddleware match host names case-insensitively.
- GZipMiddleware and SessionMiddleware keep every existing Vary header instead of only the first.
- HTTPEndpoint lists HEAD in the Allow header of 405 responses.

Go ahead and bump your version. ⬆️
