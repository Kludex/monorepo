We're hiring a Senior Rust Engineer to work on Monty at Pydantic 🦀

Monty is a Python interpreter written from scratch in Rust, so AI agents can safely run the code they write. It has no filesystem, environment or network access, starts in under a millisecond, and can be paused, dumped to bytes and resumed later. It's open source and reached 1.0 in September.

You'll work directly with Samuel Colvin. Roughly 60% of the work is on open source Monty, and the rest on Full Monty, the commercial product that runs the same sandbox behind a WebSocket.

The work includes:

- Expanding CPython compatibility
- Keeping the sandbox secure, and finding new ways to challenge it
- Performance, down to the interpreter and possibly a JIT
- Running a production service customers pay for

It's fully remote, for anyone between PT and CET. If you've written an interpreter, runtime or sandbox in Rust, apply. 🚀
