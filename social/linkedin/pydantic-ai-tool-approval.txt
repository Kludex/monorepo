A guardrail in Pydantic AI Harness doesn't have to block a tool call. It can ask a human first. ✋

ToolGuardrail runs your function before each tool call. Besides allow and block, the function can return GuardrailResult.approve(). In the image, the guard asks for approval on any deploy to prod: deploy(env='staging') ran, and deploy(env='prod') was held back.

- The run ends with a DeferredToolRequests output that lists the calls waiting.
- You resume it with the human's answers.
- A denial reaches the model as the tool's result, so the agent can explain itself or try something else.
- Tools marked requires_approval=True arrive in the same place.

Reach for it when the decision is async, needs deps, or should sit next to your other guardrail verdicts.
