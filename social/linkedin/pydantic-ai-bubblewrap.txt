BubblewrapSandbox runs a Pydantic AI agent's commands in a Linux bubblewrap sandbox, on the host they already run on. 🫧

The problem: an agent with a shell on your build box can change any file your user can.

The fix: wrap the workspace. BubblewrapSandbox(SSHWorkspace('dev@build-box', working_dir='/srv/app')) runs each command through bwrap on that host. It wraps a LocalWorkspace too.

The result: commands can write only to the working directory. They see the host's other files read-only, get a private /tmp, and have no network, because a seccomp filter blocks socket connections. network=True shares the host's network again.

It is not a boundary against an agent you don't trust. Commands can still read every file the host user can, such as SSH keys. Hide those directories with bwrap_args=['--tmpfs', path], or use a cloud sandbox.
